## Purpose

- **🔷** Phase 1 of VBP: ship a **Writer only** so we can **look at real output** from files already loaded in RooBuilder.
- **🔷** Create `src/Vbp/Writer.vala` (namespace **`Vbp`** — capital **B** only).
- **🔷** Writer works on the **in-memory `JsRender.JsRender` object** (loaded tree) — **not** responsible for parsing `.bjs` JSON.
- **🔷** Loading `.bjs` stays the **loader’s** job (`loadFromBjs` / existing CLI test flow).
- **🔷** CLI: **`--test-write-vbp`** — load via existing machinery, then `Writer.write(vbp_path)` streams sibling `.vbp` via **`GLib.DataOutputStream`** + **`GLib.File.replace`** (not `set_contents`, not a full-document string).
- **🔷** **Do not** hook `saveBJS()` / normal save yet.
- **🔷** Later phases (parent **1.0**): tokenizer → brace/bracket tree → structural parse into the same in-memory tree → round-trip. Not in **1.1**.

## Writer format requirements (from parent 1.0)

Emit using these locks; if a node feature is ambiguous, pick a readable default and note **💩** follow-up — **do not block** Phase 1 on every **💩** in **1.0**.

### Document header

- **🔷** `vbp-version = 1;`
- **🔷** File metadata from `JsRender` when non-empty: `name`, `parent`, `title`, `permname`, `modOrder`.
- **🔷** **Skip `path`** in VBP output — hangover from old JS dump behaviour; not useful / often an absolute machine path.
- **💩** `using …` lines — omit in Phase 1 unless trivial.

### Objects

- **🔷** `Type` or `Type Name { … }` where Name comes from the node’s `id` prop (no separate `id = "…"`).
- **🔷** **No `oid`** in output.
- **🔷** Empty objects may be `Type {}` or `Type Name {}`.

### Children vs named props

- **🔷** Anonymous children → bare `[ … ]` (comma between peers).
- **🔷** Nodes with `prop_name` set → **`prop_name = Type Name { … }`** on the parent (not inside `[ ]`).
- **🔷** Array slots ending in `[]` → repeat `name[] = Type { … }`.

### Props and kinds

- **🔷** Plain props: `name = value;` (quote normal strings; RAW/`$` expressions unquoted).
- **🔷** `var` fields (NodePropType.USER): **`var Type name = value;`** is public (default spelling).
  - Also accept/emit **`public` / `private` / `protected Type name = value;`** (keyword replaces `var`).
  - Writer: public USER → **`var`** (not `public`). `private` / `protected` when stored.
- **🔷** Emit order inside an object: object props (PROP/RAW/pack/ctor/args) → **`var` fields** → `construct` → `listeners [ ]` → `methods [ ]` → named object props → `[` anonymous children `]`.
- **🔷** SPECIAL **`init`** → **`construct { … }`** (opaque body).
- **🔷** SPECIAL **`pack`** → `pack = …;` on the child for Phase 1 (**💩** later Option B parent assignments when easy).
- **🔷** SPECIAL **`ctor`** → `ctor = …;`
- **🔷** SPECIAL **`args`** → `args = …;` if present.
- **🔷** LISTENER → `listeners [ … ]` (opaque bodies; **`,` between peers**).
- **🔷** METHOD → `methods [ … ]` (opaque bodies; **`,` between peers**).
- **🔷** Anonymous children also use bare `[ … ]` with `,` between peers.
- **🔷** Function-valued / RAW: `name = <opaque RHS>;`
- **🔷** Non-empty `doc`: emit `/** … */` above the node/prop — **🚫** `#` lines.

### Grammar / cosmetics

- **🔷** Indentation for humans (**2 spaces** per level — **visual only**, not significant to the parser); `;` on value statements; `,` between peers in `[ ]` (`listeners`, `methods`, anonymous children).
- **🔷** Pretty enough to re-run and compare by eye (byte-identical **💩** not required in 1.1).

## Implementation sketch

### 1. `src/Vbp/Writer.vala` — new file

**Why:** Namespace `Vbp`; Writer only builds text from an already-loaded `JsRender`.

**Where:** new file `src/Vbp/Writer.vala`.

**Depends on:** meson; caller has loaded `file` (loader, not Writer).

#### Add — `Writer` with ctor + `write(path)` 

- **Where:** new file `src/Vbp/Writer.vala`.
- **What:** Walk `file` metadata + `file.tree` → stream VBP to path.

```vala
namespace Vbp {

	public class Writer : Object {
		public JsRender.JsRender file { get; private set; }

		public Writer (JsRender.JsRender file) {
			this.file = file;
		}

		public void write (string path) throws GLib.Error {
			// File.replace + DataOutputStream; walk tree with put_string
		}
	}
}
```

### 2. `meson.build` — register source

**Why:** Compile the new file.

**Where:** Vala sources array.

#### Add

- **Where:** among `'src/….vala'` entries.
- **What:** `'src/Vbp/Writer.vala',`

**Why:** Preview path without hooking save; naming matches `--test-bjs-*`.
